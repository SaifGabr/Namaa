React Product Catalog  - Namaa Infologistics

A responsive product catalog built with React and React Router. Includes search, category filtering, sorting, pagination, and a product details page.

- Setup

1. Clone the repo
   bash
   git clone <your-repo-url>
   cd product-catalog
   
2. Install dependencies
   npm install
 
3. Run the dev server
   npm run dev
   
4. Open the app at [http://localhost:5173](http://localhost:5173)

   
- The Stack
  *  React
  *  React Router
  *  Vite
  *  CSS (custom properties / variables for theming)

 
- Up-And running
  * Product list with image, title, price, category, and "View Details"
  * Real-time search by product name
  * Category filtering with reset
  * Sorting (price/name, depending on what you implemented)
  * Pagination
  * Dynamic product details page 
  * Loading and empty states
  * Responsive layout (mobile, tablet, desktop)
